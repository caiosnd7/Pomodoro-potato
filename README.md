# Pomodoro-potato

🎮 **Play it here: https://caiosnd7.github.io/Pomodoro-potato/**

I always wanted a pomodoro app, so I built one with some gaming aspects (quests, XP and accomplishments) to make learning a little easier.

- Adjustable focus timer (5–60 min) with an early-finish button
- A mage that levels up from 1 to 30 and evolves at levels 10 and 20
- Daily tasks and Notion missions that give XP
- Loot boxes, a daily chest and a 100-slot stash
- Dota 2-style attributes (Strength, Agility, Intelligence)
- History calendar with daily notes, plus backup export/import

Built with plain HTML, CSS and JavaScript.
